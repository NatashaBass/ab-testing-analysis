# Проверка статистических гипотез и анализ A/B-теста

## О проекте

Проект посвящён применению статистических методов для анализа пользовательского поведения и оценки результатов эксперимента.

Работа состоит из двух частей:

1. проверка гипотезы о различиях в активности пользователей Яндекс Книг из Москвы и Санкт-Петербурга;
2. оценка A/B-теста нового интерфейса интернет-магазина.

Цель проекта — проверить статистические гипотезы на реальных пользовательских данных и определить, привело ли изменение продукта к значимому улучшению целевой метрики.

## Задачи

- подготовить данные для статистического анализа;
- проверить независимость сравниваемых выборок;
- изучить распределение пользовательской активности;
- сформулировать нулевую и альтернативную гипотезы;
- провести t-тест для двух независимых выборок;
- проверить корректность проведения A/B-теста;
- оценить достаточность размера выборки;
- рассчитать конверсию в покупку;
- провести статистическое сравнение конверсий;
- сопоставить фактический результат A/B-теста с целевым эффектом.

## Часть 1. Проверка гипотезы — Яндекс Книги

Исследовалась гипотеза о том, что пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг, чем пользователи из Москвы.

### Подготовка данных

Исходный датасет содержал 8 784 наблюдения.

Было выявлено 244 повторяющихся идентификатора пользователей. Все эти пользователи присутствовали одновременно в данных Москвы и Санкт-Петербурга, поэтому для обеспечения независимости выборок они были исключены.

После очистки осталось 8 296 пользователей:

- Москва — 5 990;
- Санкт-Петербург — 2 306.

Среднее время активности:

- Москва — 10,85 часа;
- Санкт-Петербург — 11,26 часа.

Распределение активности в обеих группах имело выраженную правостороннюю асимметрию.

### Проверка гипотезы

Для сравнения использован односторонний t-тест Уэлча для двух независимых выборок при уровне значимости α = 0,05.

Получено:

`p-value = 0,3318`

Нулевую гипотезу отвергнуть не удалось.

Статистически значимых оснований утверждать, что пользователи Санкт-Петербурга проводят в приложении больше времени, чем пользователи Москвы, не обнаружено.
