# Проверка статистических гипотез и анализ A/B-теста

## О проекте

Проект посвящён применению статистических методов для анализа пользовательского поведения и оценки результатов эксперимента.

Работа состоит из двух частей:

1. проверка гипотезы о различиях в активности пользователей Яндекс Книг из Москвы и Санкт-Петербурга;
2. оценка A/B-теста нового интерфейса интернет-магазина.

Цель проекта — проверить статистические гипотезы на реальных пользовательских данных и определить, привело ли изменение продукта к значимому улучшению целевой метрики.

## Задачи

- подготовить данные для статистического анализа;
- проверить независимость сравниваемых выборок;
- изучить распределение пользовательской активности;
- сформулировать нулевую и альтернативную гипотезы;
- провести t-тест для двух независимых выборок;
- проверить корректность проведения A/B-теста;
- оценить достаточность размера выборки;
- рассчитать конверсию в покупку;
- провести статистическое сравнение конверсий;
- сопоставить фактический результат A/B-теста с целевым эффектом.

## Часть 1. Проверка гипотезы — Яндекс Книги

Исследовалась гипотеза о том, что пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг, чем пользователи из Москвы.

### Подготовка данных

Исходный датасет содержал 8 784 наблюдения.

Было выявлено 244 повторяющихся идентификатора пользователей. Все эти пользователи присутствовали одновременно в данных Москвы и Санкт-Петербурга, поэтому для обеспечения независимости выборок они были исключены.

После очистки осталось 8 296 пользователей:

- Москва — 5 990;
- Санкт-Петербург — 2 306.

Среднее время активности:

- Москва — 10,85 часа;
- Санкт-Петербург — 11,26 часа.

Распределение активности в обеих группах имело выраженную правостороннюю асимметрию.

### Проверка гипотезы

Для сравнения использован односторонний t-тест Уэлча для двух независимых выборок при уровне значимости α = 0,05.

Получено:

`p-value = 0,3318`

Нулевую гипотезу отвергнуть не удалось.

Статистически значимых оснований утверждать, что пользователи Санкт-Петербурга проводят в приложении больше времени, чем пользователи Москвы, не обнаружено.

## Часть 2. Анализ A/B-теста

Интернет-магазин протестировал новую версию интерфейса. Целевая метрика — конверсия зарегистрированных пользователей в покупку в течение первых семи дней после регистрации.

Ожидаемый эффект по техническому заданию — увеличение конверсии минимум на 3 процентных пункта.

## Проверка корректности теста

В исходных данных:

- 14 525 записей об участниках двух A/B-тестов;
- 787 286 пользовательских событий.

После удаления 36 318 полных дубликатов осталось 750 968 событий.

В тесте `interface_eu_test` первоначально участвовали 10 850 пользователей.

Группы были распределены практически равномерно, пересечений между группами A и B не обнаружено.

При проверке конкурирующего эксперимента выявлены пользователи, которые могли подвергаться воздействию другого теста. После очистки осталось 10 628 участников:

- группа A — 5 277;
- группа B — 5 351.

Для анализа использовались только события, совершённые в течение первых семи дней после регистрации.

После фильтрации осталось 62 383 события от всех 10 628 пользователей.

## Проверка размера выборки

Параметры расчёта:

- базовая конверсия — 30%;
- минимальный обнаруживаемый эффект — 3 п.п.;
- мощность — 80%;
- уровень значимости — 5%.

Необходимый размер выборки составил:

- 3 762 пользователя на группу;
- 7 524 пользователя всего.

Фактический размер обеих групп превышал необходимый, поэтому выборка признана достаточной.

## Результаты A/B-теста

Количество пользователей, совершивших покупку:

- группа A — 1 454 из 5 277;
- группа B — 1 579 из 5 351.

Конверсия:

- группа A — 27,55%;
- группа B — 29,51%.

Абсолютный прирост составил:

**+1,95 процентного пункта.**

Для проверки различий использован односторонний z-тест пропорций.

Получено:

`p-value = 0,0128`

При α = 0,05 различие статистически значимо.

Новый интерфейс статистически значимо повысил конверсию в покупку.

Однако фактический прирост составил 1,95 п.п., что ниже целевого значения 3 п.п. Поэтому целевой эффект, заданный в техническом задании, достигнут не был.

## Вывод

Статистический анализ показал разные результаты для двух исследуемых задач.

В Яндекс Книгах наблюдаемая разница между средней активностью пользователей Москвы и Санкт-Петербурга статистически значимой не оказалась.

В A/B-тесте новый интерфейс статистически значимо увеличил конверсию с 27,55% до 29,51%, однако фактический прирост +1,95 п.п. оказался меньше запланированных +3 п.п.

Таким образом, статистическая значимость изменения не означает автоматически достижение продуктовой цели: результат эксперимента необходимо оценивать одновременно с точки зрения статистики и ожидаемого бизнес-эффекта.
